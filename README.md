# README - Verdant OS

## Overview
Verdant OS is a Solarpunk-themed web operating system characterized by a glassy UI effect and a functional desktop environment. Developed for the Takumi Hackathon, it provides a simulated OS experience within a browser 

## Project Details
- **Inspiration**: The system design is inspired by macOS and Windows interfaces 
- **Team**: Team - CM SHRI GANDHI NAGAR [cite: 3].
- **Contributors**: Udbhav Dalmia, Shashwat Tiwari, and Om Tiwari 
- **Tech Stack**: Built using HTML5, Tailwind CSS, JavaScript (ES6+), and GSAP for animations and window dragging.

## Features
- **Authentication**: Interactive lock screen with real-time clock and a login portal .
- **Applications**: Includes a Calculator, a dynamic Calendar, and a persistent Notepad.
- **Persistence**: The Notepad uses `localStorage` to ensure user notes remain saved across sessions .
- **Customization**: Integrated settings allow users to change system wallpapers and view theme details .
