# Verdant OS

## Overview
Verdant OS is a Solarpunk-themed web OS characterized by a glassy UI effect, commonly named as "Glassmorphism" and a functional desktop environment. Developed for the Takumi Hackathon, it provides an OS experience within the browser.

## Project Details
- **Inspiration**: The system design is inspired by macOS and Windows interfaces 
- **Team**: Team - CM SHRI GANDHI NAGAR.
- **Contributors**: Udbhav Dalmia, Shashwat Tiwari, and Om Tiwari 
- **Tech Stack**: Built using HTML5, Tailwind CSS, JavaScript, and GSAP for animations and window dragging.

## Features
- **Authentication**: Interactive lock screen with a clock and a login portal .
- **Applications**: Includes a Calculator, a dynamic Calendar, and a Notepad.
- **Storage**: The Notepad uses `localStorage` to ensure notes remain saved across different logins.
- **Customization**: Settings allow users to change system wallpapers.
